Welcome to KythOS
Immutable gaming & development desktop — KythOS

This installer will guide you through installing KythOS on your computer.

A network connection is required to install KythOS.
Connect using the network icon in the bottom-right panel before clicking Start Install. Your disk, account, timezone, and kernel selections will remain if you need to reconnect.

What happens:
  1. Select a target disk
  2. Choose install mode — erase full disk or install alongside existing OS
  3. Choose your kernel
  4. Set hostname, timezone, and user account
  5. Download and write KythOS to disk

⚠ The selected disk or partition will be erased.
Back up any data you need before continuing.

Finding KythOS on reboot

Your PC may still boot straight into your existing OS by default. If KythOS doesn't appear automatically, restart and open your firmware's boot menu — commonly by pressing F12, F10, F9, or Esc right after power-on — and choose KythOS from the list. You can also change the default boot order from your firmware setup screen once KythOS appears there.
One more step: Secure Boot key enrollment

On your first reboot, a one-time Secure Boot enrollment screen will appear before KythOS loads. This is normal — it is a one-time security setup:

  1. Press any key when prompted
  2. Select Enroll MOK
  3. Select Continue
  4. Enter password: kyth
  5. Select Yes, then Reboot

After this, KythOS will boot normally every time.
